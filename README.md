# Agentic AI for Safety Monitoring with Construction Risk Analytics

## Project Overview
This project aims to develop an AI-powered construction safety monitoring system that identifies potential hazards, assesses site risks, and presents safety insights through an interactive dashboard.

## Milestone 1 — Progress Update (Week 2)

### Completed
- **React Dashboard:** Developed an initial dashboard using React.js, Tailwind CSS, and Vite.
- **Risk Scoring:** Implemented a basic Python risk engine that generates a risk score, risk level, and safety recommendation.
- **Hazard Visualization:** Added a dashboard table to display site hazards, severity levels, and incident statuses.
- **Dashboard Metrics:** Added sample safety metrics and a weekly trend visualization.
- **Project Setup:** Configured the development environment and Git/GitHub version control.
- **Build Verification:** Successfully built the React frontend for production.

### Current Implementation
The project currently contains a frontend prototype and a basic Python risk-scoring module. The dashboard uses sample data to demonstrate the intended user interface and safety analytics workflow.

### Work in Progress
- Integrating site-monitoring data with the risk engine.
- Verifying automated hazard identification from input data.
- Developing and validating the Site Risk Agent.
- Connecting the frontend dashboard to backend risk-analysis results.
- Testing the complete workflow.

### Technology Stack
- **Frontend:** React.js, Tailwind CSS, Vite
- **Backend / Risk Analytics:** Python
- **Visualization:** Dashboard metrics and hazard trends
- **Version Control:** Git and GitHub

### Milestone 1 Objective
Establish the initial Site Risk Agent, site-monitoring data workflow, hazard detection, risk scoring, and dashboard visualization.
